# 用語集とざっくり仕様

このスキルは、用語、単位、ざっくり仕様を素早く確認するための参照です。詳細な正は `docs/specification.md` と `src/types/simulation.ts` です。

## アプリ概要

Lifeplan Simulator は、年間の収入・支出・資産配分を入力し、将来の手元資金を推定するアプリです。モンテカルロ法とヒストリカル法で資産推移を計算し、テーブルとチャートで表示します。

## 単位と表現

- 金額: コード内部は円単位。仕様書の入力説明では万円表記が使われる箇所がある。
- 年齢: `initialAge` から `endAge` まで。終了年齢は最大 120 歳。
- 期間: `endAge - initialAge`。結果は開始時点を含むため、データ点は期間 + 1。
- 率: 小数の fraction。`0.05` は 5%、`0.1` は 10%。
- 税/手数料率: 売却時の控除率。`0 <= rate < 1` を有効範囲とする。

## 主要用語

- モンテカルロ法: 期待リターンとリスクからランダムな年次リターンを生成し、多数回の結果分布を見る手法。
- ヒストリカル法: 1996-2025 年の市場・インフレデータを循環させた30通りの開始位置でシミュレーションする手法。
- 循環データ: 期間にかかわらず、30年分のデータを繰り返し利用する仕組み。実在した連続期間ではなく合成シナリオになる。
- パーセンタイル: 結果分布の位置。`p10` は下位 10%、`median` は中央値、`p90` は上位寄りの結果を表す。
- 現金上限: 現金がこの値を超えたとき、余剰分を株式または仮想通貨へ自動投資する基準。
- 現金下限: 現金がこの値を下回ったとき、株式または仮想通貨を売却して補填する基準。
- 資産下限: 株式・仮想通貨を最低限残すための基準。下限割れ時は現金で補填する。
- 取り崩し優先資産: 現金不足時に先に売却する資産。`crypto`、`stock`、`random`。
- 積立先優先資産: 現金上限超過時に余剰現金を入れる資産。`crypto`、`stock`、`random`。
- 住宅ローン年数: シミュレーション開始から住宅ローン支出を計上する年数。
- リタイア年齢: この年齢までは給与所得を計上し、翌年以降は給与を 0 とする。
- 医療・介護費発生年齢: この年齢以降、医療・介護費を支出に含める。
- 娯楽費減少開始年齢: この年齢以降、娯楽費を毎年 `entertainmentExpensesDeclineRate` で減少させる。

## 主要パラメータ

- `initialAge`: シミュレーション開始時の年齢。
- `retirementAge`: 給与所得を計上する最終年齢。
- `endAge`: シミュレーション終了年齢。
- `initialStockValue`、`initialCryptoValue`、`initialCashValue`: 初期資産。
- `livingExpenses`、`entertainmentExpenses`、`housingMaintenance`、`medicalCare`、`housingLoan`: 年間支出。
- `salary`、`realEstateIncome`: 年間収入。
- `investmentReturnRate`、`investmentRisk`: モンテカルロ法の株式リターンとリスク。
- `cryptoReturnRate`、`cryptoRisk`: モンテカルロ法の仮想通貨リターンとリスク。
- `inflationRate`: モンテカルロ法のインフレ率。
- `stockRegion`: ヒストリカル法の株式データ選択。`sp500`、`nikkei`、`world`。
- `inflationRegion`: ヒストリカル法のインフレデータ選択。`japan`、`us`、`world`。
- `numSimulations`: モンテカルロ法の実行回数。

## ざっくり計算仕様

1. 年初の株式・仮想通貨に年次リターンを適用する。
2. 給与、不動産所得、生活費、娯楽費、住宅維持費、医療・介護費、住宅ローンを使って年間収支を計算する。
3. 年間収支を現金に反映する。
4. 現金が上限を超えたら、余剰分を優先設定に従って投資する。
5. 現金が下限を下回ったら、優先設定に従って資産を売却し、税/手数料を差し引いた手取りを現金に入れる。
6. 株式・仮想通貨が下限を割ったら、現金から補填する。
7. 総資産、株式、仮想通貨、現金を年齢ごとに記録する。
8. 複数シミュレーションの結果から `p10/p25/median/p75/p90` と資産内訳の中央値を作る。

インフレ率は生活費・娯楽費・住宅維持費・医療介護費・不動産所得を翌年に向けて調整する。株式・仮想通貨・現金の残高にはインフレ率を掛けない。

## 表示仕様の概要

- 結果テーブル: 年齢、資産額のパーセンタイル、株式・仮想通貨・現金の中央値を表示する。
- 資産推移グラフ: 年齢ごとの資産額を表示する。
- 資産内訳グラフ: 株式・仮想通貨・現金の構成を表示する。
- AI アドバイザー: シミュレーション結果と設定から助言文を生成する。外部 API 設定は保存対象になるため、テストや fixture では dummy 値を使う。
